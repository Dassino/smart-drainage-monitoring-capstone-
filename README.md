# Smart Drainage Monitoring and Flood Prediction System

Capstone project — ICS 4D, Strathmore University.
Three-stage ML pipeline (Isolation Forest, Random Forest, LSTM) for 
urban drainage blockage and flood risk detection, using ESP32 sensor 
nodes, MQTT, and PostgreSQL.

## Structure
- `firmware/` — ESP32 sensor node code (Arduino)
- `backend/` — Database schema and MQTT ingestion
- `data-collection/` — Gas sensor calibration logging
- `docs/` — Proposal and design diagrams
